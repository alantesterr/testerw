# Для автора сайта

Эта инструкция — для того, кто ведёт StudyPlay для своей группы или курса.
Всё, что нужно студентам, делается через веб-интерфейс, а файлы вы кладёте
в репозиторий на GitHub.

## 1. Вход студентов

Студенты входят просто: указывают **группу** на экране приветствия. Логины и
пароли вести не нужно — старый файл `accounts.json` удалён (в нём пароли лежали
открыто, это небезопасно). Сайт не хранит пароли от Platonus и Timetable.

## 2. Группы и папки курса

У каждой группы — своя папка с расписанием и материалами.

1. В сайте: **Настройки → Для автора → Группы и папки**. Добавьте группу
   (например, `ИР-252`) и папку (`ir-252`, латиницей). Нажмите **Скачать groups.json**.
2. Положите файл в репозиторий как `data/groups.json` (замена файла) и опубликуйте.

Расписание и материалы группы собираются на сайте и выгружаются файлами:

- **Настройки → Данные → schedule.json** — расписание группы.
- **Настройки → Данные → manifest.json** — список материалов, тестов и ссылок.

Структура в репозитории:

```
data/
  groups.json              список групп и папок
  ir-252/
    schedule.json          расписание группы ИР-252
    manifest.json          материалы, тесты, ссылки
    files/
      Философия/Лекция 1.pdf
      Информационно-коммуникационные технологии/тест.txt
  ik-252/
    schedule.json
```

Путь к файлу материала в `manifest.json` — вида
`data/ir-252/files/<предмет>/<файл>`. Имя папки группы видно под каждой строкой
в окне «Группы и папки».

## 3. Как студенты получают обновления

1. Поменяйте файлы группы и **обязательно измените `"version"`** в них
   (например `2026-10-23.1` → `2026-10-24.1`). При скачивании через сайт версия
   меняется сама.
2. Сделайте `git push` (или загрузите файлы через веб-интерфейс GitHub).
3. Когда студент откроет «Расписание», сайт заметит новую версию и предложит
   «Пришло новое расписание курса» с кнопками «Обновить» / «Позже». Вручную:
   **Настройки → Данные → Обновить данные курса**.
4. Личные данные студентов (заметки, свои ссылки, своё расписание, журнал оценок,
   загруженные оценки) при этом не стираются.

## 4. Подготовить тесты для группы

- Создайте тест в **Дизайнере** (Настройки → Для автора → Дизайнер тестов),
  экспортируйте в TXT (с картинками) или `.studyplay.json`.
- Положите файл в `data/<группа>/files/<предмет>/` и пропишите его в `manifest.json`
  (kind: `test`). Либо выгрузите manifest.json из сайта — он соберётся сам.
- Можно попросить ИИ составить тест: промпт в разделе «Для автора → Промпт для ИИ».

## 4а. Конспекты (вкладка «Конспекты»)

Конспект — это PDF, перенесённый на сайт в виде данных, чтобы ответы раскрывались,
а тесты решались прямо на странице.

```
data/<группа>/notes/
  index.json        ← список конспектов группы
  philosophy.json   ← сам конспект (лекции, разделы, блоки)
  cpp.json
```

`index.json`: `{ "version": "...", "notes": [ { "id", "subject", "short", "title", "file", "pdf" } ] }`,
где `pdf` — путь к оригиналу в `data/<группа>/files/<предмет>/` (кнопка «Открыть PDF»).

Файл конспекта: `{ title, sub, intro: [блоки], lectures: [ { id, n, label, title, source, sections } ] }`.
Раздел: `{ kind: "text" | "qa" | "tasks" | "test", id, title, blocks, pdf }`.
`pdf` — где этот текстовый раздел лежит на страницах PDF: `[{ p: страница, t: верх, b: низ }]`
(в пунктах от низа страницы); по нему вид «Как в PDF» вырезает куски страниц. У задачи
может быть `plain` — пояснение «Простыми словами» (HTML). Блоки:
`p`, `h`, `ul`/`ol`, `table`, `note` (Запомни / Нюанс / Источник), `code`, `out`
(пример работы программы), `qa` (вопрос + скрытый ответ; у задач — решение),
`quiz` (вопросы теста в формате Тестера с правильными ответами из ключа).

**Как добавить новый конспект.** PDF переносится инструментом из папки
`tools/pdf-notes/` (разбор по шрифтам и координатам текста, см. README там).
Каждый новый PDF после разбора нужно проверить глазами: таблицы, код, ключи тестов.
Старые данные не трогайте вручную — пересоберите и замените файл целиком.

## 5. Расписание и оценки из Platonus/Timetable

Сайт их **не загружает автоматически** — это осознанное решение ради
безопасности (см. README, раздел про сервер-посредник). Варианты:

- **Расписание**: студент сохраняет страницу Timetable (Ctrl+S) и загружает её,
  либо вы выкладываете `schedule.json` группы на GitHub (способ выше).
- **Оценки**: студент сохраняет свой журнал из Platonus и загружает файлом.
  Формат разбора — гибкий, его можно поправить (см. docs/РЕДАКТИРОВАНИЕ.md).

## 6. Своя иконка и название

- Иконка — `assets/favicon.svg`.
- Название «StudyPlay» и ссылки на сайты вуза — `js/config.js` и строки в
  `js/i18n/*.js` (поиск по `StudyPlay`).
