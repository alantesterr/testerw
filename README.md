# StudyPlay

Учебный помощник для студентов: **расписание, папки с предметами, тестер,
оценки и плеер** с вопросами во время просмотра. Работает как обычная
веб-страница — её можно бесплатно опубликовать на GitHub Pages.

Сайт **не хранит пароли** от Platonus и Timetable и не заходит на эти сайты
за вас. Расписание и оценки вы приносите файлами, которые сохраняете сами.
Подробнее — ниже и в [docs/КАК-ПОЛЬЗОВАТЬСЯ.md](docs/КАК-ПОЛЬЗОВАТЬСЯ.md).

## Что умеет

- **Расписание** — вид «Неделя» и «День», занятия по цветам (лекция, практика,
  лабораторная, семинар). Нажатие на занятие открывает папку предмета.
- **Папки с предметами** — материалы, ссылки (Telegram и др.), тесты и личные
  заметки. Файлы автора курса приходят с GitHub, личные хранятся в браузере.
- **Тестер** — тесты из TXT, DOC, DOCX и JSON. Один или несколько правильных
  ответов, ввод ответа с клавиатуры, картинки, перевод, работа над ошибками.
- **Дизайнер тестов** — создание и редактирование вопросов, экспорт в TXT,
  DOCX, DOC, JSON (Настройки → Для автора). Рассчитан на компьютер: на телефоне
  сначала показывается предупреждение.
- **Оценки** — журнал в стиле Shokan: все предметы из расписания появляются сами,
  можно добавлять свои. Вводятся оценки по одной (или среднее), РК1, РК2 и экзамен;
  рейтинг и итоговая считаются сами, подсказка показывает, сколько нужно для 70+ (сразу с запасом до 71):
  рейтинг = текущая·60% + РК1·20% + РК2·20%; итог = рейтинг·60% + экзамен·40%.
- **Плеер** — видео, аудио и YouTube. Каждые N минут активного просмотра видео
  останавливается и появляются вопросы из Тестера. Прогресс вопросов сохраняется,
  под видео — лента (пройденные / текущий / предстоящие).
- **Конспекты** — лекции по предметам прямо на сайте, в порядке как в PDF:
  конспект → вопросы и задачи (ответ раскрывается кнопкой «Показать ответ / решение»)
  → тест по лекции (как в Тестере, можно пройти заново) → следующая лекция.
  Вид «Как в PDF» (конспект — настоящими страницами PDF) или «Текстом»; у задач C++ —
  блок «Простыми словами» с примером. Слева оглавление, кнопка «На весь экран», «Открыть PDF». Сайт помнит, где вы
  остановились, и лучший результат каждого теста. Сейчас есть (ИР-252): Философия 2.0 (с кнопкой «Где ответ в конспекте» и пробным РК1), Философия (первая версия), C++, Архитектура компьютера (только вид PDF, 51 задача с разбором), Исследование операций (вид PDF: 15 тем + теория игр, 56 задач — условие видно, решение под кнопкой, пробный РК с ответами).
- **Темы** — светлая и тёмная; **языки** — русский, казахский, английский;
  **размер шрифта** — 6 уровней. Отдельно для расписания (Shokan и Timetable)
  есть «Стандарт / Меньше / Ещё меньше» — считается от общего размера и меняет
  только расписание. Всё запоминается на устройстве.
- **Тест** — внизу одна панель: слева «Сверхпоиск», «Режим ИИ», «Перевести»,
  справа «Назад» / «Далее». Автоперевод (переключатель прямо под «Перевести» и в Настройках) и горячие клавиши (← → вопросы,
  1–9 вариант, Enter ответ / дальше, Esc снять фокус) — в Настройках → Тестер и плеер.

## Как запустить локально

Это набор статических файлов — нужен простой веб-сервер (открывать `index.html`
двойным кликом нельзя: браузер заблокирует загрузку данных).

Любой из вариантов, смотря что установлено:

```bash
# Python 3
python -m http.server 8080
```

```bash
# Node.js
npx serve -l 8080
```

Затем откройте в браузере `http://localhost:8080`.

> Если ни Python, ни Node нет — установите [расширение Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)
> в VS Code и нажмите «Go Live», либо сразу опубликуйте сайт на GitHub Pages (ниже).

## Как опубликовать на GitHub Pages (бесплатно)

1. Создайте репозиторий на GitHub (например `studyplay`).
2. Загрузите в него все файлы этого проекта (кнопка **Add file → Upload files**
   на сайте GitHub, либо через Git — см. ниже).
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)`. Сохраните.
4. Через 1–2 минуты сайт будет доступен по адресу
   `https://ВАШ-НИК.github.io/studyplay/`.

Через Git из командной строки:

```bash
git init
git add .
git commit -m "StudyPlay"
git branch -M main
git remote add origin https://github.com/ВАШ-НИК/studyplay.git
git push -u origin main
```

## Как хранятся данные и пароли

- **Пароли от Platonus и Timetable нигде не хранятся.** Сайт их не спрашивает.
  Вы сами, уже войдя на сайт вуза в своём браузере, сохраняете нужную страницу
  или выгрузку в файл и загружаете его в StudyPlay. Так данные остаются только
  на вашем устройстве.
- **Профиль** (имя и группа), настройки, тесты, прогресс плеера, журнал оценок,
  импортированные оценки — хранятся в `localStorage` вашего браузера.
- **Крупные файлы** (видео, PDF, вложения предметов) — в IndexedDB браузера.
- **Данные курса** (расписание и материалы для всей группы) — публичные файлы
  в папке `data/<группа>/` вашего репозитория на GitHub. Паролей там нет.

Старый сайт хранил логины и пароли открыто в файле `accounts.json` — это было
небезопасно. Здесь этого файла **нет** и быть не должно.

## Структура проекта

```
index.html              точка входа
css/                    дизайн-система и стили разделов
  tokens.css            все цвета, отступы, радиусы, размеры шрифтов
  base.css, components.css, layout.css, pages.css
js/
  config.js             настройки автора (ссылки на сайты вуза) — без паролей
  core/                 ядро: утилиты, хранилище, переводы, настройки, окна, каркас
  i18n/                 словари ru / kk / en (по одному ключу = одна строка)
  services/             профиль (auth), группы (api), импорт оценок (data)
  features/             разделы: расписание, папки, тестер, дизайнер, плеер,
                        оценки, конспекты (notes.js), настройки, секундомер
                        + общий движок тестов
  data/ai-prompt.js     мастер-промпт для ИИ (генерация тестов)
assets/                 иконка сайта, DOCX-промпт для ИИ
data/
  groups.json           список групп и их папок
  <группа>/schedule.json, manifest.json, files/<предмет>/…
  <группа>/notes/       конспекты для вкладки «Конспекты» (index.json + файлы)
tools/pdf-notes/        перенос PDF-конспекта в данные сайта (для автора)
docs/                   инструкции (ниже)
```

## Можно ли сделать автоматическую загрузку из Platonus/Timetable?

Технически — да, но для этого нужен отдельный сервер-посредник, который принимает
логин и пароль студента и входит на сайт вуза (браузер сам этого сделать не может
из-за ограничений безопасности). Такой посредник работает с чужими паролями,
поэтому в этом проекте он намеренно **не реализован**: выбран более безопасный
путь — загрузка файлов вручную. Если вы всё же решите его сделать, размещайте его
отдельно и никогда не храните пароли; но помните, что это повышает риски.
