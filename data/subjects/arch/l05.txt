Лекция 5. Комбинационные схемы: сумматоры, шифраторы, дешифраторы, мультиплексоры

## Что такое комбинационная схема
**Комбинационная** схема — выход зависит только от текущих входов, памяти нет. Подал ту же комбинацию — получил тот же результат. Примеры: сумматоры, умножители, шифраторы, дешифраторы, мультиплексоры, компараторы. Схемы с памятью (триггеры, счётчики, регистры) — **последовательностные**.

## Полусумматор
Складывает два одноразрядных числа A и B. Таблица: 0+0 = 00, 0+1 = 01, 1+0 = 01, 1+1 = 10.
- **Сумма S = A ⊕ B** (исключающее ИЛИ): 1, когда входы разные.
- **Перенос P = A · B** (И): 1, только когда оба 1.
Полусумматор не учитывает перенос из младшего разряда, поэтому годится только для самого младшего разряда.
! Ловушка: если сумму сделать через ИЛИ, то 1 + 1 даст S = 1 — ошибка; нужен XOR.

## Полный сумматор
Три входа: A, B и перенос из младшего разряда **Cin**; два выхода: S и **Cout**.
- S = A ⊕ B ⊕ Cin — 1, когда единиц нечётное количество.
- Cout = A·B + Cin·(A ⊕ B) — 1, когда единиц хотя бы две.
- Собирается из **двух полусумматоров и элемента ИЛИ**: первый складывает A и B, второй — результат и Cin, ИЛИ объединяет переносы.
Пример: 1 + 0 + 1 = 10₂ → S = 0, Cout = 1; 1 + 1 + 1 = 11₂ → S = 1, Cout = 1.

## Многоразрядный сумматор и умножитель
Для n-разрядных чисел ставят n полных сумматоров в цепочку: Cout каждого → Cin следующего (**последовательный перенос**). Недостаток — задержка растёт с разрядностью; быстрые сумматоры используют ускоренный перенос.
Пример: 011 + 101 = 1000 (3 + 5 = 8) — четвёртый бит выходит на выход переноса.
Вычитание: A − B = A + (доп. код B): B инвертируют и подают Cin = 1.
**Умножитель** работает как умножение столбиком: частичные произведения (элементы И) сдвигаются и складываются сумматорами.

## Дешифратор
Преобразует **двоичный код** на входах в активный сигнал на **одном выходе** с этим номером. n входов → 2ⁿ выходов (полный дешифратор). Код 101 → активен Y5.
- Линейный дешифратор: на каждый выход свой элемент И со всеми входами (с инверсиями или без). Для 2→4: Y0 = Ā1·Ā0, Y1 = Ā1·A0, Y2 = A1·Ā0, Y3 = A1·A0.
- Вход разрешения (Enable): пока он неактивен, все выходы неактивны. Из двух дешифраторов 3→8 с разрешением собирают 4→16.
- Применение: выбор микросхемы памяти по адресу, выбор устройства, управление индикатором.

## Шифратор
Обратное устройство: **номер активного входа → двоичный код**. 2ⁿ входов → n выходов (8→3). Активен вход 6 → код 110.
Шифратор 4:2: D0 → 00, D1 → 01, D2 → 10, D3 → 11 (A1 = D2 + D3, A0 = D1 + D3).
**Приоритетный** шифратор при нескольких активных входах выдаёт код самого старшего. Так работает клавиатура и контроллер прерываний.

## Мультиплексор
Передаёт на **один выход** сигнал **одного из входов**; номер входа задаёт адрес. 2ⁿ входов данных — n адресных входов: 4→1 — 2 адреса, 8→1 — 3, 16→1 — 4.
- MUX 2→1: F = S̄·D0 + S·D1.
- Адрес S1S0 = 10 → на выход идёт D2.
- Применение: выбор регистра на вход АЛУ, перевод параллельного кода в последовательный, реализация любой функции (на входы данных подают столбец таблицы истинности).
Мультиплексор ещё называют **коммутатором** (в маркировке — КП, например 74151 = К155КП7).

## Демультиплексор
Один вход данных D → на один из 2ⁿ выходов, выбранный адресом. «Распределитель». Получается из дешифратора: адрес на входы, данные — на вход разрешения.
| Устройство | Что делает | Пример применения |
| MUX | много входов → один выход | выбор регистра на вход АЛУ |
| DEMUX | один вход → выбранный выход | распределение сигнала |
| Дешифратор | двоичный код → линия выбора | адресация памяти |
| Шифратор | активная линия → двоичный код | клавиатура |

## Компаратор и маркировка микросхем
**Компаратор** сравнивает числа: выходы «больше», «равно», «меньше». Равенство двух битов — элемент равнозначность (XNOR); для 4-разрядных чисел — 4 XNOR и один 4И.
Маркировка серии 155: **ИМ** — сумматор (К155ИМ3 = 4-разрядный, 7483), **ИД** — дешифратор (74138 — 3→8 с инверсными выходами), **ИВ** — шифратор (74148), **КП** — мультиплексор (74151).
! Запомни: дешифратор и демультиплексор «расширяют» (выходов больше), шифратор и мультиплексор «сжимают».
