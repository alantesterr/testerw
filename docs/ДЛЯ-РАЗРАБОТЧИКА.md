# StudyPlay — инструкция для разработчика

Этот файл для второго разработчика (в том числе на Mac). Здесь описано, как устроен
сайт, как его запустить, где что лежит и как выкладывать изменения.

- **Сайт:** https://alantesterr.github.io/testerw/
- **Репозиторий:** https://github.com/alantesterr/testerw (ветка `main`)
- Сайт статический: HTML, CSS и JavaScript **без сборки**, без Node и без сервера.
  Его раздаёт GitHub Pages. После `git push` в `main` сайт обновляется у всех за 1–2 минуты.

---

## 1. Два способа менять сайт

| Что нужно | Как |
|---|---|
| Добавить или убрать тест, лекцию, ссылку, карточки; создать группу; поправить расписание | **Без кода**: на сайте Настройки → вкладка **Разработчик**, потом «Опубликовать» |
| Новая функция, исправление, оформление | **Код**: правишь файлы, проверяешь локально, `git push` |

Раздел «Разработчик» публикует через GitHub API личным ключом (fine-grained token
с правом *Contents: Read and write* на этот репозиторий). Каждый создаёт ключ сам:
вкладка «Точки сохранения» → «Подключить ключ», там пошаговая инструкция. Ключ
хранится только в браузере. **Никогда не вставляй ключи и пароли в код и файлы.**

---

## 2. Запуск на Mac

```bash
git clone https://github.com/alantesterr/testerw.git
cd testerw
python3 -m http.server 8099
```

Открой http://localhost:8099. Редактор — любой: VS Code, Cursor или Claude Code.

После правок обнови страницу с очисткой кэша: **Cmd + Shift + R**. Сайт ставит
офлайн-режим (Service Worker, файл `sw.js`). Если кажется, что изменения не
видны, открой DevTools → Application → Service Workers → **Unregister** и обнови
страницу ещё раз.

Чтобы проверить телефонный вид, включи в DevTools режим телефона (Cmd + Shift + M),
ширина 375 px.

## 3. Где что лежит

```
index.html            подключает все стили и скрипты (порядок важен)
sw.js                 офлайн-режим и быстрое открытие
css/                  tokens (цвета, размеры) → base → components → layout → pages → features → ui2
js/config.js          ссылки на Platonus и Timetable
js/core/              каркас: util (SP.*-помощники, SP.lib), store (localStorage), i18n, drag (перетаскивание списков),
                      settings, ui (окна, уведомления), shell (меню, разделы), ui2 (вкладки
                      Настроек, справочник, обучение), mem (общая память ошибок)
js/services/          группы (api.js), профиль и группа (auth.js), обновление данных (data.js)
js/features/          разделы, один файл на раздел:
  hub.js                данные расписания и папок (слои: своё → Timetable → курс с GitHub)
  period.js             учебный период: недели учёбы и каникулы (вне — пустое расписание)
  schedule.js           «Расписание»
  subjects.js           «Папки» (вкладки Файлы · Тесты · Карточки; перетаскивание — SP.dragSort)
  philo.js              «Философия»: 500 тестов с разбором и учебник (data/philo/), вход из Настроек
  homework.js           «Домашка»: своё (localStorage sp-hw), для группы (data/<группа>/homework.json), фото (IndexedDB sp-hw-photos)
  cards.js              «Карточки» (устные вопросы)
  test-engine.js        разбор тестов (.txt/.docx/.doc), проверка ответов
  bank.js, tester.js    «Тестер»
  feed.js               «Лента» (тест в стиле TikTok)
  ext-bridge.js         связь с расширением Chrome (extension/)
  grades.js             «Оценки» — вид как в Shokan, НЕ МЕНЯТЬ без просьбы владельца
  player.js             «Плеер» (скрыт из меню по умолчанию)
  notes.js, mynotes*.js конспекты
  designer.js           редактор тестов
  settings-view.js      «Настройки»
  dev.js                «Разработчик»: вкладки, папки, точки сохранения, помощь
  dev-groups.js         «Разработчик → Группы» и «Общие предметы»
  dev-schedule.js       «Разработчик → Расписание» (наглядная сетка: вид Timetable / Shokan)
js/i18n/ru.js         ВСЕ тексты сайта (kk.js и en.js — переводы; чего нет, берётся из ru)
js/data/guide.js      справочник на сайте + новости (NEWS)
js/data/ai-prompt.js  промпты для ИИ (тесты и карточки)
data/                 содержимое для студентов (см. ниже)
extension/            расширение Chrome «тесты во время видео»
app/android/          Android-приложение (Capacitor, открывает сайт)
docs/                 инструкции
old/                  старая версия сайта, не трогать
```

Всё живёт в одном глобальном объекте `window.SP`. Раздел регистрируется через
`SP.views.register('имя', { mount, show, refresh })`, адрес раздела — `#/имя`.
Тексты берутся через `SP.t('ключ', { параметры })`, иконки — через `SP.icon('имя')`
(список иконок в `js/core/icons.js`).

## 4. Данные: группы, расписание, папки

```
data/groups.json                    список групп: [{ "name": "ИР-252", "folder": "ir-252" }, …]
data/<группа>/schedule.json         расписание группы
data/<группа>/manifest.json         файлы папок предметов группы
data/<группа>/files/<Предмет>/…     сами файлы
data/<группа>/notes/                конспекты
data/<группа>/homework.json         домашка «для всей группы» (пишет разработчик из раздела «Домашка»)
```

**manifest.json**

```json
{
  "version": "2026-11-16.1",
  "include": [{ "from": "ir-252", "subjects": ["Философия", "Экзамен"] }],
  "files": [
    { "subject": "Философия", "kind": "test",  "name": "Тест.docx",   "path": "data/mr-252/files/Философия/Тест.docx", "size": 1234 },
    { "subject": "Философия", "kind": "cards", "name": "Билеты.txt",  "path": "…" },
    { "subject": "Философия", "kind": "material", "name": "Лекция.pdf", "path": "…" },
    { "subject": "Философия", "kind": "link", "name": "Telegram", "url": "https://t.me/…" }
  ]
}
```

- `include` — **общие предметы**: группа видит файлы этих предметов из папки другой
  группы, без копирования. Так у МР-252 и ИР-252 одна база тестов.
- `version` — меняй при каждой правке. Сайт студентов сравнивает версию и сам
  подхватывает новые файлы.
- `kind`: `test` — вкладка «Тесты»; `cards` — вкладка «Карточки» (без таких файлов
  вкладки нет); `material` — «Файлы»; `link` — ссылка.

**schedule.json**: `period` (учебный период: `{ "start": "2026-09-01", "weeks": 15, "breaks": [{ "from", "to", "name" }] }`, вне его и в каникулы недели пустые), `timeSlots` (время пар), `subjects` (id, name, teacher) и `schedule`
(пары: `day` от 0 = пн до 5 = сб, `slotId`, `subjectId`, `kind`, `room`, `building`).
Удобнее всего править это в «Разработчик → Расписание»: неделя там выглядит как у студента,
пары добавляются «＋», меняются нажатием и перетаскиваются.

**homework.json** — домашка для всей группы:

```json
{ "version": "2026-11-17.1", "items": [
  { "id": "g-…", "text": "Прочитать §5", "subject": "Философия", "due": "2026-11-20", "at": "2026-11-17T10:00:00Z",
    "photos": ["data/ir-252/homework/ph-….jpg"] }
] }
```

Пишет его раздел «Домашка» (переключатель «Для всей группы» виден только с ключом GitHub)
одним коммитом **без** точки сохранения. Задания со сроком больше месяца назад убираются
при следующей записи. Отметки «сделано» у каждого студента свои (`sp-hw-done`).


**data/philo/** — раздел «Философия» (Настройки → вкладка «Философия», `js/features/philo.js`):

- `lecture.md` — учебник: `# Тема N. … {#tN}`, `## N.M … {#tN-M}`, перед каждым блоком строка `{#tN-M-pK}`; абзацы, списки `- `, таблицы `|`, врезки `> 💡` / `> ⚠️` / `> 👤`, `**жирный**`, `` `код` ``.
- `questions.json` — 500 тестов базы: `{ id: "b1", n, t: "t1", q, o: [5 вариантов, правильный первый], e: [почему неверен каждый], k: «запомни», y: почему верно, l: [id блоков учебника], c?: спорный ключ, d?: номер первого такого же вопроса }`.
- `extra.json` — новые вопросы в том же виде (`id: "x-t1-01"`).
- Как делались: промпт `docs/ПРОМПТ-ФИЛОСОФИЯ.md` → другой чат Claude → `questions.jsonl` соединён с вариантами из «Философия докс.docx» по номеру. Прогресс студента — `localStorage sp-philo`.
Форматы тестов и карточек описаны в «Разработчик → Помощь» и в промптах (`js/data/ai-prompt.js`).

## 5. Правила при каждом изменении кода

1. **Версия файлов.** В `index.html` у всех `?v=…` поставь новую одинаковую версию
   (например `20261120a`). Без этого телефоны студентов покажут старый код.
2. **Новый файл скрипта** подключи в `index.html` в нужном месте и с той же версией.
3. **Тексты** — только в `js/i18n/ru.js`, не прямо в коде.
4. **Справочник и новости** — `js/data/guide.js`: добавь запись в `NEWS` сверху и
   поправь главу, если поменялось поведение. Коротко то же самое запиши в
   `docs/КАК-ПОЛЬЗОВАТЬСЯ.md` («Изменения ДД.ММ»).
5. **Проверь** на ширине телефона (375 px) и на компьютере, в светлой и тёмной теме.
   В консоли браузера не должно быть красных ошибок.
6. **Не трогай без просьбы владельца:** вид «Оценок» (как в Shokan), вид Расписания
   Shokan, протокол расширения Chrome.
7. **Пароли и ключи** никогда не попадают в репозиторий.

## 6. Публикация и откат

- Обычный способ: `git add …`, `git commit -m "…"`, `git push origin main`.
- Перед большой правкой поставь точку сохранения (тег):
  ```bash
  git tag backup-2026-11-20-pered-chem-to && git push origin backup-2026-11-20-pered-chem-to
  ```
  На сайте точки видны в «Разработчик → Точки сохранения», там же кнопка «Вернуть сайт
  сюда». Храним **не больше 4** точек, старые удаляются сами при новой точке с сайта.
- Опубликовал ли GitHub Pages: вкладка **Actions** в репозитории или
  `gh api repos/alantesterr/testerw/pages/builds/latest`.

## 7. Частые задачи

- **Новая группа:** «Разработчик → Группы → Новая группа», затем «Общие предметы» →
  «Опубликовать». После этого «Расписание» → выбрать группу → заполнить → «Опубликовать».
- **Тест для всех:** «Разработчик → Папки → предмет → ＋ Тест» → «Опубликовать».
- **Устные вопросы:** «＋ Карточки», формат `Вопрос: … / Ответ: …`, пример есть в «Помощи».
- **Домашка всей группе:** раздел «Домашка» → включить «Для всей группы» → «Добавить».
- **Перетаскивание в новом списке:** `SP.dragSort(контейнер, { item, key, onSort, target, onDrop })`
  из `js/core/drag.js` (описание параметров — в начале файла).
- **Где «Оценки»:** их нет в меню — переключатель «Домашка · Оценки» (`SP.homework.switchHtml`).
- **Новая настройка:** значение по умолчанию — в `js/core/settings.js`, строка в
  `js/features/settings-view.js` (нужный `section(...)`), раскладка по вкладкам — `TABS` в `js/core/ui2.js`.
- **Новый раздел сайта:** новый файл в `js/features/` с `SP.views.register`,
  подключить в `index.html`, пункт меню — `MAIN` в `js/core/shell.js`.

## 8. Скрытое и старое (работает, но спрятано)

- **Плеер** — скрыт из меню; его заменяют Лента и расширение Chrome. Включается так:
  Настройки → Ещё → «Показывать „Плеер“ в меню».
- **Конспекты** — вкладка в папке предмета убрана, код оставлен (`notes.js`, `mynotes*.js`).
- **Секундомер**, **Дизайнер тестов**, **Игра** — в Настройки → Ещё.
- Имя студента больше не спрашивается: сайту нужна только группа.
