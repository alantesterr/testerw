Архитектура ЭВМ. Тема 5. Комбинационные схемы: сумматоры, шифраторы, дешифраторы — вопросы (формат Тестера, с пояснениями)

<question>Шифратор (кодер) — это комбинационное устройство, которое:
<variantright>преобразует сигнал на одном из входов (единичный код) в двоичный код номера этого входа
<variant>преобразует двоичный код в сигнал на одном из выходов
<variant>выбирает один из входов и передаёт его на выход
<variant>складывает два двоичных числа
<explain>Решение: шифратор — «из номера кнопки в двоичный код». Например, у клавиатуры 10 клавиш-цифр: нажали клавишу 5 (активен вход 5) → на выходе код 101. Обратное устройство (двоичный код → один активный выход) — дешифратор. Выбор входа — мультиплексор, сложение — сумматор.
Ответ: номер активного входа → двоичный код.

<question>Дешифратор (декодер) — это комбинационное устройство, которое:
<variantright>преобразует входной двоичный код в активный сигнал на одном выходе с номером, равным этому коду
<variant>преобразует номер активного входа в двоичный код
<variant>сдвигает двоичный код на один разряд
<variant>хранит двоичный код
<explain>Решение: дешифратор — «из двоичного кода в номер выхода». Подали код 101 → активен выход 5, остальные неактивны. Применение: выбор микросхемы памяти по адресу, выбор устройства, управление индикаторами.
Ответ: двоичный код → активен выход с этим номером.

<question>Приоритетный шифратор отличается от обычного тем, что:

<question>Мультиплексор — это комбинационное устройство, которое:

Ответ: один вход → выход по адресу.

<question>Полусумматор — это схема, которая:
<variantright>складывает два одноразрядных двоичных числа A и B, выдавая сумму S и перенос P (без учёта переноса из младшего разряда)

<variant>складывает два многоразрядных числа

<explain>Решение: полусумматор — «половина» сумматора: у него 2 входа (A, B) и 2 выхода (S — сумма, P или C — перенос). Он не умеет учитывать перенос, пришедший из младшего разряда, поэтому годится только для самого младшего разряда.
Ответ: складывает два бита, без входного переноса.

<question>Какие логические элементы образуют полусумматор?
<variantright>исключающее ИЛИ (сумма) и И (перенос)

<explain>Решение: таблица сложения двух бит: 0+0 = 00, 0+1 = 01, 1+0 = 01, 1+1 = 10.

• Перенос P = 1, только когда оба 1 → P = A·B (И).
Ответ: XOR и И.

<question>Формула суммы полного сумматора:
