Лекция 6. Триггеры: назначение, классификация, временные диаграммы

## Зачем нужен триггер
Логические элементы ничего не помнят: убрал входной сигнал — исчез и результат. А компьютеру нужно хранить данные. **Триггер** — устройство с двумя устойчивыми состояниями (Q = 0 или Q = 1), которое хранит **1 бит**, пока его не переключат.
- Выходы: прямой **Q** и инверсный **Q̄** (всегда противоположны).
- «Установлен» — Q = 1, «сброшен» — Q = 0.
- Из триггеров строят регистры, счётчики, статическую память (SRAM).
Триггеры — **последовательностные** схемы: выход зависит и от входов, и от предыдущего состояния.

## RS-триггер
Простейший триггер: **S** (Set — установить 1) и **R** (Reset — сбросить в 0). Память получается из двух элементов с **перекрёстной обратной связью**.
- На **ИЛИ-НЕ** (прямые входы, активна 1): S=R=0 — хранение, S=1 — запись 1, R=1 — запись 0, **S=R=1 запрещено**.
- На **И-НЕ** (инверсные входы S̄, R̄, активен 0): S̄=R̄=1 — хранение, **S̄=R̄=0 запрещено** (оба выхода становятся 1).
- Запрещённая комбинация: две противоположные команды сразу, после снятия состояние непредсказуемо.
! Запомни: на ИЛИ-НЕ запрещено «1 и 1», на И-НЕ — «0 и 0».

## Синхронизация: уровень и фронт
Асинхронный RS переключается от любой помехи. Поэтому добавляют вход синхронизации **C** (такт): триггер слушает входы, только когда разрешено.
- **Статический вход (по уровню):** пока C = 1, триггер «открыт».
- **Динамический вход (по фронту):** реагирует только в момент перепада C. **Передний фронт** — 0→1, **задний (спад)** — 1→0. На схеме треугольник «>», кружок перед ним — срабатывание по спаду.
- Синхронный RS: при C = 0 — хранение, при C = 1 работает как обычный RS.

## D-триггер
Один информационный вход **D**. По активному синхроимпульсу Q принимает значение D — «фотографирует» вход. Запрещённой комбинации нет.
- **D-защёлка** (по уровню): пока C = 1, Q повторяет D; при C = 0 запоминает последнее значение.
- **D-триггер по фронту:** смотрит на D только в момент фронта C.
- Называют **триггером задержки** и **информационным**; бывает только синхронным.
- На временной диаграмме Q меняется только в моменты активного фронта C.

## T-триггер и деление частоты
**T** (Toggle) переключается в противоположное состояние на каждом импульсе. Два импульса возвращают его в исходное — это «счётчик до двух».
- Частота на выходе в 2 раза меньше входной: T-триггер — **делитель частоты на 2**.
- n последовательно соединённых T-триггеров делят частоту на 2ⁿ.
- D-триггер становится T-триггером, если соединить Q̄ с D.

## JK-триггер — универсальный
J — как S, K — как R, но комбинация 1-1 разрешена и означает «переключись».
| J | K | После активного фронта |
| 0 | 0 | хранение |
| 1 | 0 | запись 1 |
| 0 | 1 | запись 0 |
| 1 | 1 | переключение (как T) |
Из JK получают все остальные: J = K = 1 → T; J = D, K = D̄ → D. В EWB тактовый вход JK срабатывает по **заднему фронту**.

## Двухступенчатый триггер (Master-Slave)
Два триггера подряд: **ведущий** принимает данные, пока C = 1, **ведомый** переписывает их на выход, когда C падает. Выход меняется уже после того, как вход закрыт, — нет «гонок» в схемах с обратной связью (счётчиках). Обозначение — ТТ.

## Асинхронные входы, время установки и метастабильность
- **PR (Preset)** и **CLR (Clear)** мгновенно, без такта, ставят Q = 1 или Q = 0. С кружком — активны нулём.
- **Setup time** — вход D должен быть стабилен некоторое время ДО фронта; **hold time** — некоторое время ПОСЛЕ.
- Если нарушить — **метастабильность**: выход «зависает» между 0 и 1. Защита — синхронизатор из двух последовательных триггеров.
- **Регистр** — набор триггеров для хранения многоразрядного кода (16 разрядов — 16 триггеров). **Регистр сдвига** по каждому такту сдвигает код на разряд: влево — умножение на 2, вправо — деление; превращает последовательный код в параллельный.
