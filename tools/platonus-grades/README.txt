Программа StudyPlay (Windows): оценки + расписание со ссылками
================================================================

Одна программа, одно окно. Умеет:
  • ОЦЕНКИ из Platonus (platonus.kgu.kz) — во вкладку «Оценки» на сайте;
  • РАСПИСАНИЕ из Timetable (timetable.kgu.kz) со ссылками, которые преподаватели
    оставляют в поле «Мессенджер: ID конференции», — во вкладку «Расписание».
Пароли хранятся только на вашем компьютере в зашифрованном виде (config.json рядом
с программой; расшифровать может только ваша учётная запись Windows). Сайт их не видит.

ЧТО В АРХИВЕ
  StudyPlay.vbs   — ЗАПУСКАТЬ ЭТОТ ФАЙЛ (двойной щелчок)
  grades_app.ps1  — сама программа (не трогать)
  README.txt      — эта инструкция

ПЕРВЫЙ РАЗ (~2 минуты)
  1. Распакуйте архив в постоянную папку, например «Документы\StudyPlay».
     Не запускайте прямо из архива и потом не переносите папку.
  2. Дважды щёлкните StudyPlay.vbs. Если Windows покажет «Windows защитила ваш
     компьютер» — «Подробнее» → «Выполнить в любом случае».
  3. Раздел «1. Вход»: логин и пароль от Platonus, галочка «Запомнить пароль».
     В Timetable пароль другой? Снимите галочку «В Timetable тот же логин и пароль»
     и введите логин и пароль для Timetable. Кнопка «Проверить вход» проверит оба сайта.
  4. Раздел «2. Связь с сайтом»: нажмите «Подключить». Кнопки «Обновить из Platonus»
     и «Обновить расписание» на сайте заработают сразу во всех браузерах.
     «Открывать StudyPlay в» — в каком браузере открывать сайт (по умолчанию тот,
     где StudyPlay уже открыт). «Ярлык на рабочий стол» — чтобы не искать папку.
  5. «Получить всё» — оценки и расписание со ссылками появятся во вкладках окна.
     «Открыть StudyPlay» — откроет сайт и сразу передаст туда всё полученное.

ДАЛЬШЕ — С САЙТА
  «Оценки» → шестерёнка → «Обновить из Platonus» — только оценки;
  «Расписание» → «Обновить расписание» — только расписание со ссылками.
  Браузер спросит «Открыть приложение?» → «Открыть» (галочка «Всегда разрешать»
  уберёт вопрос). Программа работает незаметно, всё появится через несколько секунд.
  Первый раз браузер попросит доступ к буферу обмена → «Разрешить».
  Автообновление: Настройки → Инструменты — отдельно для оценок и для расписания.

С ТЕЛЕФОНА
  В окне программы: «Получить всё» → «Файл для StudyPlay». Отправьте файл себе
  (например, в Telegram), на сайте: «Оценки» → «Скачать» → «Загрузить файл оценок».
  Придут и оценки, и расписание со ссылками.

ОБНОВЛЕНИЕ ПРОГРАММЫ
  Замените файлы в папке новыми (config.json не трогайте — там сохранённый пароль),
  откройте StudyPlay.vbs и, если написано «подключены по-старому», нажмите
  «Обновить подключение». Старые файлы start.vbs, connect.bat, disconnect.bat,
  test-schedule.bat после этого можно удалить.

ЕСЛИ ЧТО-ТО НЕ ТАК
  • Ночной перерыв: Platonus обычно не работает примерно с 23:00 до 7:00 — оценки
    в это время не обновятся. Это не ошибка программы. Расписания это не касается.
  • Не чаще раза в минуту: программа и сайт сами следят, чтобы Platonus и Timetable
    не заблокировали вход (отдельно для каждого).
  • Ничего не происходит после «Открыть» на сайте — в окне программы должно быть
    «● подключены». Если нет — нажмите «Подключить».
  • Окно программы открылось само — пароль не сохранён: введите его с галочкой
    «Запомнить пароль» и нажмите «Получить всё».
  • «Ваш вход в систему блокирован» — Platonus блокирует вход на ~3 минуты после
    нескольких неверных паролей. Подождите и проверьте пароль.
  • Предмет не обновился — у карточки на сайте сильно другое название. Переименуйте
    карточку как в Platonus (стрелка на карточке → «Название»).

ОТКЛЮЧИТЬ
  В окне программы «Отключить». Удалить сохранённые пароли — удалите config.json.
