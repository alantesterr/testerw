Лекция 4. Формы логических выражений: ДНФ, КНФ. Карты Карно

## Зачем нужны нормальные формы
Одну и ту же функцию можно записать множеством формул. Чтобы по таблице истинности сразу получить формулу и потом собрать схему, используют стандартные формы — **ДНФ** и **КНФ**.
- **ДНФ** (дизъюнктивная нормальная форма) — «сумма произведений»: Ā·B + A·C.
- **КНФ** (конъюнктивная нормальная форма) — «произведение сумм»: (A + B)·(Ā + C).
В схемотехнике ДНФ — это слой элементов И, а на выходе ИЛИ; КНФ — слой ИЛИ, а на выходе И.

## СДНФ: по строкам с единицами
**Совершенная** ДНФ — каждое произведение (минтерм) содержит ВСЕ переменные.
- Шаг 1. Выделить строки таблицы, где F = 1.
- Шаг 2. Для каждой строки записать произведение всех переменных: если переменная = 0 — с отрицанием, если 1 — без.
- Шаг 3. Соединить произведения знаком ИЛИ.
Пример: F = 1 на наборах 01 и 10 → Ā·B + A·B̄ (это XOR). Строке 101 соответствует минтерм A·B̄·C.

## СКНФ: по строкам с нулями
**Совершенная** КНФ — по строкам, где F = 0, и правило «наоборот»: переменная = 1 пишется с отрицанием, = 0 — без; внутри скобки — ИЛИ, скобки перемножаются.
Пример: набор 101 с F = 0 даёт макстерм (Ā + B + C̄). У функции И (A·B) три нуля — три скобки.
! Запомни: СДНФ — строки с 1, ноль → с чертой. СКНФ — строки с 0, единица → с чертой.

## Зачем упрощать (минимизация)
СДНФ даёт верную, но длинную формулу — много элементов. Упрощённая формула даёт ТУ ЖЕ таблицу истинности, но схема дешевле, быстрее и надёжнее.
**Цена схемы** — суммарное число входов всех элементов. Например, F = A·B + C на 2И и 2ИЛИ стоит 2 + 2 = 4.
Упрощать можно законами (склеивание A·B + A·B̄ = A, поглощение A + A·B = A, A + Ā·B = A + B) или графически — **картами Карно**.

## Карта Карно
Это та же таблица истинности, нарисованная прямоугольником так, что **соседние клетки отличаются одной переменной**. Тогда склеивание видно глазами.
- Строки и столбцы подписывают **кодом Грея**: 00, 01, 11, 10 (а не 00, 01, 10, 11!).
- 2 переменные — 4 клетки, 3 — 8 (2×4), 4 — 16 (4×4).
- В клетку пишем значение функции на этом наборе.

## Правила группировки
- Объединяем соседние единицы в группы по **1, 2, 4, 8, 16** клеток (степень двойки).
- Группа — прямоугольник или квадрат, **без диагоналей**.
- Карта «свёрнута в бублик»: крайние столбцы и строки — соседи, **четыре угла** — тоже группа.
- Группы берём **как можно больше**, а их число — **как можно меньше**; группы могут перекрываться.
- Группа из 2ᵏ клеток убирает k переменных: пара — одну, четвёрка — две, восьмёрка — три.
- Неопределённые наборы (Ф, X) можно считать 1 или 0 — как выгоднее.
! Ловушка: группа из 3 клеток или по диагонали — ошибка.

## Как читать группу
В группе остаются только переменные, которые НЕ меняются внутри неё. Пример: F(A,B,C) = 1 на 000, 010, 100, 110 — у всех C = 0, остальное меняется → F = C̄. Четыре угла карты 4 переменных (0000, 0010, 1000, 1010) → B̄·D̄.
Пример из силлабуса: ∑(1, 3, 5, 7, 10, 11, 14, 15) → группа «D = 1 при A = 0» (Ā·D) и группа «A = 1, C = 1» (A·C): Q = Ā·D + A·C.

## Синтез комбинационной схемы
Полный путь от задачи к схеме:
- 1) по условию составить таблицу истинности;
- 2) записать СДНФ;
- 3) минимизировать (законы или карта Карно);
- 4) построить схему в нужном базисе.
Пример из силлабуса: выход 1, если хотя бы два из трёх входов равны 1 (мажоритарная функция). После упрощения Q = A·B + A·C + B·C.
Для базиса И-НЕ: над ДНФ ставят двойное отрицание и раскрывают по де Моргану: A·B + C·D = ¬(¬(A·B)·¬(C·D)) — только элементы И-НЕ.
В EWB это делает **Logic Converter**: схема → таблица → упрощённое выражение → схема (в том числе только на И-НЕ).
