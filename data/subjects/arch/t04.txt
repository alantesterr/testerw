Архитектура ЭВМ. Тема 4. Формы логических выражений: ДНФ, КНФ. Карты Карно — вопросы (формат Тестера, с пояснениями)

<question>Совершенная дизъюнктивная нормальная форма (СДНФ) — это:
<variantright>дизъюнкция (сумма) конъюнкций, в каждую из которых входят все переменные (с отрицанием или без)
<variant>конъюнкция дизъюнкций
<variant>любое выражение без скобок
<variant>выражение, содержащее только операцию НЕ
<explain>Решение: СДНФ — «сумма произведений», где каждое произведение (минтерм) содержит ВСЕ переменные. Например, для F(A,B,C): Ā·B·C + A·B̄·C. Каждый минтерм описывает одну строку таблицы, где F = 1.
СКНФ — наоборот, «произведение сумм» (по строкам, где F = 0).
Ответ: сумма полных произведений.

<question>Как построить СДНФ по таблице истинности?
<variantright>взять строки, где функция равна 1; для каждой записать произведение всех переменных (переменную с 0 — с отрицанием); соединить произведения знаком ИЛИ
<variant>взять строки, где функция равна 0, и перемножить их
<variant>сложить все переменные таблицы
<variant>взять только первую и последнюю строку таблицы
<explain>Решение (алгоритм из методички):
1) выделить строки, где F = 1;
2) для каждой строки записать конъюнкцию всех переменных: если переменная в строке = 0 — пишем её с отрицанием, если 1 — без;
3) соединить все конъюнкции знаком ИЛИ (+).
4) при необходимости упростить склеиванием.
Ответ: строки с F = 1 → произведения → сумма.

<question>Функция F(A, B) равна 1 только на наборах 01 и 10. Её СДНФ:
<variantright>Ā·B + A·B̄
<variant>A·B + Ā·B̄
<variant>Ā·B̄ + A·B
<variant>(A + B)·(Ā + B̄)·A
<explain>Решение: строка 01: A = 0 → Ā, B = 1 → B → Ā·B. Строка 10: A·B̄. Сумма: Ā·B + A·B̄. Это функция «исключающее ИЛИ» (A ⊕ B).
Ответ: Ā·B + A·B̄.

<question>Какой минтерм (конъюнкция в СДНФ) соответствует строке таблицы A = 1, B = 0, C = 1?
<variantright>A·B̄·C
<variant>Ā·B·C̄
<variant>A + B̄ + C
<variant>A·B·C
<explain>Решение: в СДНФ переменная, равная 0, пишется с отрицанием, равная 1 — без отрицания: A = 1 → A, B = 0 → B̄, C = 1 → C → A·B̄·C. Проверка: при 101 это произведение равно 1·1·1 = 1, а на остальных наборах — 0.
Ответ: A·B̄·C.

<question>Какой макстерм (дизъюнкция в СКНФ) соответствует строке таблицы A = 1, B = 0, C = 1, где функция равна 0?
<variantright>Ā + B + C̄
<variant>A + B̄ + C
<variant>A·B̄·C
<variant>Ā·B·C̄
<explain>Решение: в СКНФ берут строки, где F = 0, и правило «наоборот»: переменная, равная 1, пишется с отрицанием, равная 0 — без: A = 1 → Ā, B = 0 → B, C = 1 → C̄ → (Ā + B + C̄). Проверка: на наборе 101 сумма 0 + 0 + 0 = 0 ✓.
Ответ: Ā + B + C̄.

<question>Функция F(A, B, C) = 1 на наборах 001, 011, 101 (строки 1, 3, 5). Сколько конъюнкций будет в её СДНФ? (введите число)
<variant_keyboard>3
<explain>Решение: в СДНФ по одной конъюнкции на каждую строку, где F = 1. Таких строк 3 → 3 конъюнкции: Ā·B̄·C + Ā·B·C + A·B̄·C.
Ответ: 3.

<question>Упростите СДНФ: Ā·B̄·C + Ā·B·C + A·B̄·C.
<variantright>Ā·C + B̄·C
<variant>C
<variant>A·B·C
<variant>Ā + B̄
<explain>Решение: склеиваем пары, отличающиеся одной переменной (минтерм Ā·B̄·C можно использовать дважды):
• Ā·B̄·C + Ā·B·C = Ā·C (исчезла B);
• Ā·B̄·C + A·B̄·C = B̄·C (исчезла A).
Итог: Ā·C + B̄·C = C·(Ā + B̄).
Ответ: Ā·C + B̄·C.

<question>Функция F(A, B, C) = 1 на наборах 100, 101, 110, 111 (то есть когда A = 1). Чему равна упрощённая функция?
<variantright>F = A
<variant>F = A·B·C
<variant>F = B + C
<variant>F = Ā
<explain>Решение: все четыре набора имеют A = 1, а B и C принимают все возможные значения. Значит, B и C на результат не влияют. Склеивание: A·B̄·C̄ + A·B̄·C = A·B̄; A·B·C̄ + A·B·C = A·B; A·B̄ + A·B = A.
Ответ: F = A.

<question>Что такое «цена схемы» по Квайну?
<variantright>общее количество входов всех логических элементов схемы
<variant>стоимость микросхем в рублях
<variant>количество выходов схемы
<variant>число строк таблицы истинности
<explain>Решение: цена схемы — мера её сложности: считают суммарное число входов всех элементов (И, ИЛИ, НЕ). Чем меньше цена, тем проще и дешевле схема. Поэтому функцию упрощают (минимизируют) перед построением схемы.
Ответ: общее число входов логических элементов.

<question>Зачем упрощать (минимизировать) логическую функцию перед построением схемы?
<variantright>чтобы схема содержала меньше элементов и входов — была дешевле, быстрее и надёжнее
<variant>чтобы функция давала другие значения
<variant>чтобы увеличить число переменных
<variant>упрощать не нужно, это ничего не меняет
<explain>Решение: упрощённая функция даёт ТЕ ЖЕ значения на всех наборах (таблица истинности не меняется), но её реализация требует меньше логических элементов. Меньше элементов — меньше цена схемы, меньше задержка сигнала и выше надёжность.
Ответ: меньше элементов при той же работе.

<question>Студент составлял СДНФ для F(A, B) = 1 на наборе A = 0, B = 1 и записал минтерм A·B̄. Где ошибка?
<variantright>отрицание ставится над переменными, равными 0: правильно Ā·B
<variant>ошибки нет
<variant>нужно записать A + B̄
<variant>нужно записать A·B
<explain>Решение: в СДНФ переменная с значением 0 пишется с отрицанием, с 1 — без. A = 0 → Ā, B = 1 → B → Ā·B. Студент поставил отрицания «наоборот» (так делают для СКНФ). Проверка: A·B̄ при 01 = 0·0 = 0 — не подходит.
Ответ: правильно Ā·B.

<question>Что такое карта Карно?
<variantright>таблица для графической минимизации логической функции, где соседние клетки отличаются значением только одной переменной
<variant>таблица перевода чисел из двоичной системы в десятичную
<variant>схема соединения логических элементов
<variant>таблица кодов ASCII
<explain>Решение: карта Карно — это та же таблица истинности, но нарисованная прямоугольником так, что соседние клетки отличаются одной переменной. Тогда склеивание (A·B + A·B̄ = A) видно глазами: соседние единицы объединяют в группы, и лишние переменные исчезают. Диаграмма Вейча — похожая таблица (немного иначе подписана), применяется так же.
Ответ: таблица для минимизации, соседние клетки отличаются одной переменной.

<question>В каком порядке подписывают строки и столбцы карты Карно для двух переменных?
<variantright>00, 01, 11, 10 (код Грея)
<variant>00, 01, 10, 11
<variant>11, 10, 01, 00
<variant>в любом порядке
<explain>Решение: используется код Грея — соседние коды отличаются ровно одним битом: 00 → 01 → 11 → 10. Если написать по порядку 00, 01, 10, 11, то соседние 01 и 10 отличаются двумя битами — склеивать их нельзя, и карта «сломается».
Ответ: 00, 01, 11, 10.

<question>Сколько клеток в карте Карно для функции 4 переменных? (введите число)
<variant_keyboard>16
<explain>Решение: по одной клетке на каждый набор переменных: 2⁴ = 16 (карта 4 × 4). Для 3 переменных — 8 (2 × 4), для 2 — 4 (2 × 2).
Ответ: 16.

<question>Какого размера могут быть группы (контуры) единиц на карте Карно? (выберите ДВА верных утверждения)
<variantright>число клеток в группе — степень двойки: 1, 2, 4, 8, 16
<variantright>группа должна быть прямоугольником (квадратом), может переходить через край карты
<variant>группа может состоять из 3 или 6 клеток
<variant>клетки группы можно соединять по диагонали
<explain>Решение: правила группировки:
• размер группы — 1, 2, 4, 8 … (степень двойки);
• форма — прямоугольник или квадрат, без диагоналей;
• карта «свёрнута в трубку»: крайние столбцы (и строки) — соседи, угловые клетки тоже;
• группы могут перекрываться; группы берут как можно больше, а их число — как можно меньше.
Ответ: размер — степень двойки; прямоугольник, можно через край.

<question>Сколько переменных исчезает из конъюнкции, если на карте Карно объединить в группу 4 клетки? (введите число)
<variant_keyboard>2
<explain>Решение: группа из 2 клеток убирает 1 переменную, из 4 — 2 переменные, из 8 — 3 (2ᵏ клеток → исчезает k переменных). Например, в карте 4 переменных группа из 4 клеток даёт произведение из 2 переменных.
Ответ: 2.

<question>Зачем на карте Карно выбирают группы как можно больше?
<variantright>чем больше группа, тем меньше переменных в соответствующем слагаемом — выражение получается проще
<variant>чтобы карта выглядела аккуратнее
<variant>большие группы обязательны по ГОСТ
<variant>размер группы ни на что не влияет
<explain>Решение: каждое удвоение группы убирает ещё одну переменную. Группа из 1 клетки — полный минтерм (все переменные), из 2 — на одну меньше и т.д. Поэтому стремятся к большим группам и к минимальному числу групп.
Ответ: больше группа — меньше переменных.

<question>Функция F(A, B) = 1 на наборах 10 и 11. Минимизируйте её.

<question>Функция 4 переменных F(A, B, C, D) = 1 только в четырёх угловых клетках карты Карно: 0000, 0010, 1000, 1010. Минимизируйте её.

<question>Как синтезировать комбинационную схему по описанию её работы? Расположите этапы правильно.

<question>Чтобы реализовать функцию в базисе И-НЕ, упрощённую ДНФ преобразуют с помощью:
